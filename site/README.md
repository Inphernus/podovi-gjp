# Podovi GJP — web (Astro)

Dokumentacija projekta (naredbe, struktura, objava, podaci koji čekaju klijenta) je u [../README.md](../README.md).

Najčešće naredbe:

```bash
npm run dev      # lokalni razvoj
npm test         # unit testovi (Vitest)
npm run e2e      # e2e testovi (Playwright)
npm run check    # provjera tipova
npm run build    # produkcijski build u dist/
```
